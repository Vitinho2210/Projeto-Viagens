**Projeto Viagens**

O Projeto Viagens foi desenvolvido como um dos primeiros projetos de Programação Web, com o objetivo de praticar a criação de páginas utilizando HTML e CSS. O site apresenta conteúdos relacionados a diferentes países europeus, com páginas destinadas à Alemanha, Espanha, França, Inglaterra e Itália.

A estrutura do projeto conta com uma página principal, páginas específicas para os países, arquivos de estilização e imagens. Dessa forma, o projeto permite praticar a organização de páginas, inserção de imagens, criação de conteúdo e aplicação de estilos.

**Principais recursos:** apresentação de informações sobre diferentes países, navegação entre páginas, utilização de imagens e estilização das páginas.

**Tecnologias utilizadas:** HTML e CSS.
